Android that sends everything through Tor.

Kor OS is an Android system based on LineageOS. Network traffic from every app is routed through Tor, with no Google services by default.

Status

Kor OS is in development. There is no downloadable build yet. Follow progress on GitHub.

Follow on GitHub

What to expect

Tor for the whole system

App traffic goes through Tor. If the Tor connection drops, the internet drops too.

Built on LineageOS

A well-established open-source Android base that ships without Google apps.

Open source

Source code and build files are published on GitHub under the licenses of the projects Kor OS is based on.
